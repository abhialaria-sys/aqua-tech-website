# Free Plumber & Electrician Website

This is a simple static website that can be hosted FREE using GitHub Pages or Netlify.

## Before publishing
Open `index.html` and replace:
- `9876543210` with your real mobile/WhatsApp number
- `HOMEFIX SERVICES` with your business name
- Service area/location if needed

## Free hosting
### GitHub Pages
1. Create a free GitHub account.
2. Create a new public repository.
3. Upload `index.html` and `service-banner.png`.
4. Open Settings → Pages.
5. Select Deploy from branch → main → /(root).
6. Save. GitHub will provide a free `github.io` website address.

### Netlify
Upload the whole folder to Netlify's free static-site hosting and it will provide a free `netlify.app` address.

The website is mobile-friendly and includes Call Now and WhatsApp buttons.
